# DarkSky Studios website

Static site for GitHub Pages. No build step.

## Structure

- `/` studio home page
- `/study-with-me/` game page (Steam "Game Website URL")
- `/privacy/` privacy policy (Steam "Privacy Policy URL")

## Publish on GitHub Pages

1. Create a GitHub repository (for a free `https://USERNAME.github.io/` address, name it exactly `USERNAME.github.io`).
2. Upload all files from this folder to the repo root.
3. Repo Settings -> Pages -> Source: "Deploy from a branch" -> Branch: `main` / root.
4. After a minute the site is live.

## Before you submit the URLs to Steam

Search the files for `TODO` and fill in:

- Steam store page link and Discord invite (`study-with-me/index.html`)
- Trailer embed and screenshots (`study-with-me/index.html`)
- Real feature list (`study-with-me/index.html`)
- Contact email and a check of every section (`privacy/index.html`)

## Steam fields

- Game Website URL: `https://USERNAME.github.io/study-with-me/`
- Privacy Policy URL: `https://USERNAME.github.io/privacy/`
